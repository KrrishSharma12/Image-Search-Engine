# 📸 Image Search Engine

A simple and responsive **Image Search Engine** built using **HTML, CSS, JavaScript**, and the **Unsplash API**.  
This project allows users to search for high-quality photos instantly.

---

## 🚀 Live Demo  
🔗 **Website Link:** https://krrishsharma12.github.io/Image-Search-Engine/

---

## ✨ Features
- 🔍 Search any keyword to fetch images  
- 📷 High-quality photos from Unsplash  
- ⚡ Fast API response using JavaScript  
- 📱 Fully responsive layout  
- 🔄 Load more results  
- 🎨 Clean and modern design  

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript**
- **Unsplash API**
